# hinatamachi-nandemoya

魔法の町のなんでも屋 ― 丘の上の小さな町「ひなたまち」で、なんでも屋「ほしや」の新米店員として過ごす、ほのぼのRPG



## 遊び方

* 依頼箱から依頼を1つ選び、町マップで場所をタップして移動します。住人と話したり、✦ が光っている所を調べたりして、困りごとを解決します。
* 戦闘・ゲームオーバーはありません。どの選択肢を選んでも依頼は成功し、選んだ内容で住人の反応が少しずつ変わります。
* 1回のプレイは依頼1件（5〜10分）。進行は自動で保存され、「つづきから」で再開できます。
* 困ったら店主のシキに話しかけると、次にやることのヒントをくれます。
